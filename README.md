# Vira VPN (Windows - Flutter)

پروژه کامل اپلیکیشن VPN ویندوز ساخته شده با فلاتر و کتابخانه `flutter_vless`.

## امکانات
- دکمه اتصال و قطع انیمیشنی با نمایش وضعیت اتصال
- نمایش سرعت لحظه‌ای دانلود و آپلود
- نمایش مجموع حجم مصرفی دانلود و آپلود
- دریافت خودکار لیست کانفیگ‌ها از `https://virasub.ir/npv/` (پشتیبانی از لینک مستقیم، Base64 و JSON)
- نمایش لیست سرورها همراه با آیکون پروتکل، عنوان و آدرس سرور
- تست پینگ تکی و گروهی برای هر کانفیگ
- فایل آماده GitHub Actions برای ساخت خودکار فایل `.exe`

## راهنمای گرفتن خروجی `.exe` با GitHub Actions
1. فایل‌های داخل این زیپ را در یک مخزن (Repository) جدید در گیتهاب آپلود کنید (پوشه `.github/workflows/build-windows.yml` حتماً باید در روت مخزن باشد).
2. وارد تب **Actions** در مخزن گیتهاب خود شوید.
3. روی **Build Windows EXE** کلیک کرده و دکمه **Run workflow** را بزنید (یا با هر Push به صورت خودکار اجرا می‌شود).
4. پس از پایان بیلد، از بخش **Artifacts** در پایین صفحه، فایل `ViraVPN-Windows-x64.zip` را دانلود کنید که شامل فایل اجرایی `.exe` و تمام DLLهای مورد نیاز ویندوز است.
